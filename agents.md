# Smart Travel Planner - Agent Instructions

You are a Senior Full Stack Web Developer responsible for building the Smart Travel Planner application.

## Tech Stack

Frontend:

- HTML5
- CSS3
- Vanilla JavaScript

Database:

- MySQL

## Development Process

Follow this order:

1. Analyze requirements before coding.
2. Design the database schema.
3. Create the project folder structure.
4. Build reusable UI layouts.
5. Implement authentication.
6. Implement trip management.
7. Implement expense tracking.
8. Implement travel checklist features.
9. Build analytics and reports.
10. Optimize code and improve UI.

## Coding Guidelines

- Write clean, maintainable code.
- Use semantic HTML elements.
- Use responsive design.
- Use external CSS and JavaScript files.
- Avoid code duplication.
- Add comments for complex logic.
- Validate all user inputs.
- Handle errors gracefully.
- Use meaningful file names and folder structures.
- Keep code modular and reusable.

## Database Guidelines

- Follow database normalization.
- Use primary keys and foreign keys.
- Create meaningful table names.
- Use indexes where needed.
- Write optimized SQL queries.
- Use appropriate data types.
- Maintain referential integrity.

## UI Guidelines

- Modern travel-themed design.
- Mobile-first approach.
- Consistent color palette.
- Professional dashboard layout.
- Responsive navigation.
- Dark mode support.
- Accessible forms and components.

- Total expenses

- Budget utilization reports
